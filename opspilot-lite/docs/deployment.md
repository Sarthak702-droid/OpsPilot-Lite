# Deployment

Deploy Next.js and Go independently. Provide managed PostgreSQL and Redis, and run migrations before starting API/worker. A Redis lease prevents overlapping worker refreshes. Set `APP_ENV`, `PORT`, `DATABASE_URL`, `REDIS_URL`, `CLERK_JWKS_URL`, `CLERK_ISSUER`, `FRONTEND_ORIGIN`, and MiMo variables. The frontend needs `NEXT_PUBLIC_API_URL` and the Clerk publishable key.

SGLang belongs on a separate private GPU host. Do not publish port 30000. Use HTTPS for public frontend/API. Back up PostgreSQL before migration. Configure a private R2 bucket, the `R2_ACCOUNT_ID`, `R2_ACCESS_KEY`, `R2_SECRET_KEY`, and `R2_BUCKET` backend secrets, and allow the API to reach its S3-compatible endpoint. The backend image includes Poppler and English Tesseract OCR for PDF imports. Configure `SMTP_HOST`, `SMTP_PORT`, `SMTP_FROM`, and optional SMTP credentials for supplier emails; the server requires STARTTLS. Create at least two authorized members for separate PO approval. Investigate any uncertain send state before resolving it in the UI. Set `OTEL_EXPORTER_OTLP_ENDPOINT` to an OTLP/HTTP collector URL to export API, database, Redis, worker, and MiMo spans; tracing is disabled when unset. The provided collector config logs received spans for development.
